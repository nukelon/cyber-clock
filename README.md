# NOCTURNE · 交互式镂空机械腕表

## 在线访问与 GitHub 源码

在线网站：https://nukelon.github.io/cyber-clock/

仓库根目录为开发源码，需先 `pnpm install`，再 `pnpm dev`。执行 `pnpm build` 后，成品位于 `dist/`，其中 index.html 可离线打开。

GitHub Pages 通过 `.github/workflows/pages.yml` 自动检查、编译并部署 `dist/`。仓库的 Settings → Pages → Source 应选择 **GitHub Actions**。不要直接把 main 分支根目录当作成品发布，否则浏览器会请求未编译的 `/app/main.tsx` 并出现空白页。

## 打开离线交付包

解压交付压缩包，双击根目录的 **index.html**。所有脚本和样式均在本地，无需联网或安装依赖。保留 `assets` 文件夹的位置。支持 WebGL 2 的现代桌面及手机浏览器，需要硬件加速。

同时提供按原始需求命名的 **index.heml**（内容相同）；推荐使用标准扩展名 index.html。

## 交互

- 左键 / 单指拖动腕表旋转，中键 / 双指拖动平移，滚轮 / 双指捏合 / + − 缩放；点击机芯零件查看说明与高亮。
- **向上拖动 3D 表冠**或右侧上链区进行手动上链，向下拖动空回；也可点击「上链一圈」。表冠 4 圈对应发条轴 1 圈，满链限位。
- 初始未上链，机芯和指针保持停止；手动上链后启动。剩余储能持续消耗，耗尽时停走，上链后重新启动。
- 「拉出调时」停秒并保持储能；设定时间后确认，或推回表冠继续运行。
- 爆炸视图、分解程度、夜光、背透、自动环绕与视角重置。
- 机芯说明中可切换 0.1× 慢动作 / 1× 正常走时 / 60× 加速。速度同步作用于所有齿轮、指针和能量消耗。
- 模型获得键盘焦点后：方向键旋转，W 上链，+ − 缩放。零件列表和其他控件均支持键盘。

页面固定在当前窗口内。右上角「隐藏菜单 / 显示菜单」可切换沉浸展示，保留视角与操作状态；小屏通过零件标题旁的信息按钮查看完整说明。

## 机构与计算

本项目为自定义的手动上链机芯运动学研究，非某款商业机芯的复刻。正面观察时正角表示逆时针。

| 传动副 | 齿数 | 周期 / 转速 |
| --- | --- | --- |
| 条盒 → 中心齿轴 | 96 → 12 | 条盒 8 小时 / 圈；中心轮 1 小时 / 圈 |
| 中心轮 → 三轮齿轴 | 80 → 10 | 三轮 8 圈 / 小时 |
| 三轮 → 四轮齿轴 | 75 → 10 | 四轮 / 小秒针 1 圈 / 分钟 |
| 四轮 → 擒纵齿轴 | 96 → 8 | 擒纵轮 12 圈 / 分钟 |
| 分轮 → 过轮 → 时轮 | 10:30 × 8:32 | 分针和时针同向，12:1 减速 |

摆轮 3 Hz = 21,600 次半振动 / 小时。15 齿擒纵轮每半振动平均放行半个齿距（12°），5 秒一圈。轮系使用同一分段擒纵坐标，不能各自独立加速或漂移。主发条内端与发条轴相连，外端与转动条盒相连。正常运行期间棘轮/发条轴保持固定，条盒转动。

储能采用 **6 圈有效相对转角 × 8 小时 / 圈 = 48 小时**的声明容量。上链增量与释放量守恒。低储能降低展示振幅，但不任意改变调速频率。

所有啮合副的节圆中心距按 `(主动轮齿数 + 从动齿轴齿数) × 模数 / 2` 建立；不同轮片沿轴向分层。可查看源文件 app/mechanism.ts 的参数。

## 真实可制造性的边界

**这个网页不能证明机芯在现实中可制造、可靠运行或准确走时。**

本模型执行的是齿数与相位约束驱动的运动学仿真。虽然有可视化轮系、发条、摆轮、游丝、杠杆与红宝石轴承，仍不属于经过验证的完整制表工程设计：

- 齿形为展示用近似，未求解齿面接触、根切、摩擦和损耗。
- 游丝与主发条形变是几何表达，并非材料应力、弹性力矩或疲劳仿真。
- 擒纵采用规定运动；锁值、牵引、冲量、落差、叉瓦角度等未做接触动力学验证。
- 夹板厚度、轴向间隙、轴承配合、调时离合、上链面齿及装配干涉未提供加工公差与完整制造图。
- 48 小时储能、振幅和材质是模型参数，未经样机测量。背面刻度和爆炸层是展示布局。

因此，“按传动关系运行的交互模型”已实现；“可直接加工、且现实中必然正常运行的机芯”未得到验证，不能据此承诺。制造需要补齐参数化 CAD、接触/应力分析、材料和公差设计、装配检查及实体样机调校。

## 源码与运行

源码采用 React 19、TypeScript、Three.js、Vite，控件使用项目自带 Base UI / Shadcn。无需外部模型或贴图服务。

在 `source` 目录（或完整的 atelier 项目目录）运行：

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

Node.js ≥ 22.13。构建将自动产生 dist/index.html、dist/index.heml 及本地 assets。离线便携检查保证主脚本无需 ES module 导入。源码里的 index.html 是开发入口；请双击交付包根目录或 dist 下的成品入口。
